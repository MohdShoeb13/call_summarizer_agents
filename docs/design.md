# Visual direction

Resonant uses an original cinematic landing page inspired by Scrolltide's motion-led presentation and 21st.dev's composable React interface patterns. No template purchase, account access, copied premium code, or external visual assets are required.

Palette: midnight navy background, layered slate surfaces, muted blue-gray secondary text, pale cyan interaction accents. Semantic CSS variables define the main colors. Typography uses the Inter/Segoe UI/system sans stack; it does not rely on a font network request.

Landing: compact navigation, editorial two-line title, an animated procedural waveform, illustrative summary preview, three-step capability explanation, evidence card, and closing action. The preview is explicitly illustrative.

Workspace: stable sidebar and breadcrumb header; one primary input decision; split intake/benefit layout on desktop; four accessible result tabs; evidence navigation into a numbered transcript. Narrow screens use a history drawer and single-column result panels.

Motion: Motion scroll reveals and CSS waveform transforms. Workspace transitions remain short and limited. Reduced-motion preference removes waveform and transition animation. Radix provides tab semantics and keyboard navigation; native file input, controls, and visible focus retain browser behavior.

Sources: https://www.scrolltide.co/ and https://21st.dev/ (reviewed September 6, 2026). The UI/UX skill informed restrained workspace motion, visible focus, touch targets, and responsive sizing; the user-selected navy/cyan direction takes precedence over generic palette suggestions.
